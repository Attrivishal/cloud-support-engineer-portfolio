# Cloud Support Engineer Portfolio & 30-Day Preparation

Welcome to my Cloud Support Engineer preparation repository! This repository tracks my 30-day intensive learning journey and houses my project portfolio.

## 🗂️ Repository Structure

This repository is divided into two main parts:

### 1. 30-Days Preparation 📅
Located in the `30-Days-Preparation` folder, this section contains my day-by-day learning logs, categorized by weeks:
- **Week 1:** Bash Scripting (Fundamentals, Loops, Functions)
- **Week 2:** AWS Services (EC2, RDS, VPC, S3, IAM, CloudWatch)
- **Week 3:** Troubleshooting (Scenarios, Mock Interviews)
- **Week 4:** Projects & Applications (Building, Refining, Applying)

*Inside each day's folder, you will find a `LEARNING_LOG.md` detailing my objectives, concepts learned, practical hands-on steps, and any troubleshooting notes.*

### 2. Portfolio Projects & Documentation 💼
As I progress through the preparation, I will build out these portfolio directories:
- `PROJECT-1-MULTI-TIER-LAB/` - Multi-Tier Application Troubleshooting Lab
- `PROJECT-2-DIAGNOSTIC-SCRIPTS/` - Automated Troubleshooting Bash Scripts
- `PROJECT-3-DOCUMENTATION/` - Troubleshooting Guides & Runbooks
- `AWS-SERVICE-NOTES/` - Core AWS services reference notes
- `INTERVIEW-PREP/` - Question banks and practice scenarios
- `RESUME/` - My latest resume

## 🚀 How to Follow Along
Feel free to browse through the `30-Days-Preparation` folders. Each `LEARNING_LOG.md` is structured to act as both a journal for me and a guide for what I accomplished that day.
